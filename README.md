# todo-list-app
A responsive Todo List App using HTML, CSS, Javascript

## Features
-  Add new tasks
-  Edit existing tasks
-  Marks tasks as completed
-  Filter All, pending, and Completed tasks
-  Search tasks
-  Task categories
-  Priority levels
-  Due dates
-  Dashboard statistics
-  Progress bar
-  Local Storage support
-  Responsive design

## Technology Used
-  HTML5
-  CSS3
-  Javascript
